# Trabajo01 - Teoría de la Decisión bajo Incertidumbre

## Descripción del Proyecto

| Fichero | Descripción |
| :--- | :--- |
| `Enunciados_Trabajo01_TD.qmd` | **Documento 1 de 2.** Código fuente Quarto con los enunciados de los problemas propuestos. |
| `Enunciados_Trabajo01_TD.html` | Versión compilada en HTML del documento de enunciados. |
| `Enunciados_Trabajo01_TD.pdf` | Versión compilada en PDF (vía Typst) del documento de enunciados. |
| `Soluciones_Trabajo01_TD.qmd` | **Documento 2 de 2.** Código fuente Quarto con la resolución paso a paso y el código en R. |
| `Soluciones_Trabajo01_TD.html` | Versión compilada en HTML del documento de soluciones. |
| `Soluciones_Trabajo01_TD.pdf` | Versión compilada en PDF (vía Typst) del documento de soluciones. |
| `teoriadecision_funciones_incertidumbre.R` | Script de R con las funciones y métodos de teoría de la decisión bajo incertidumbre. |
| `README.md` | Este fichero: descripción del repositorio, componentes y organización del trabajo. |
| `trabajo01indtd2026.Rproj` | Proyecto de RStudio asociado al trabajo. |
| `.gitignore` | Ficheros auxiliares que no se versionan. |

Cada documento ejecutable se genera en dos formatos: `html` y `pdf` (con **Typst**).
